# BabiHost Internship Project Proposal

**Project Title:** Predicting Accommodation Nightly Prices for BabiHost using Cape Town Airbnb Data

**Problem:** Hosts on BabiHost (West African hospitality platform) need data‑driven price suggestions to maximise occupancy and revenue. Travellers also want fair, transparent prices. We will build a regression model that predicts nightly price based on property features.

**Approach:**
- Dataset: Inside Airbnb – Cape Town (listings.csv) as proxy for African short‑term rentals.
- Features: property type, bedrooms, accommodates, neighbourhood, availability, host verification, etc.
- Models: Linear Regression, Decision Tree, Random Forest.
- Evaluation: MAE, RMSE, R².
- Outcome: REST API (Flask) and optional Streamlit dashboard for interactive price prediction.

**Expected Deliverables:**
- Cleaned dataset + EDA visualisations.
- Trained model with hyperparameter tuning.
- Flask API that returns a price prediction.
- GitHub repository with full documentation.
